## 📌 Tentang Aplikasi

**Portal Resmi Desa Kromengan** adalah platform digital terpadu untuk tata kelola pemerintahan desa, layanan publik masyarakat, serta sarana promosi potensi wilayah (pertanian tebu, UMKM lokal, dan kebudayaan).

Aplikasi ini dibangun dengan desain yang modern, responsif, dan *user-friendly* untuk mempermudah akses informasi seluruh warga Desa Kromengan serta masyarakat umum.

## ✨ Fitur-Fitur Utama

### 🏛️ 1. Profil & Informasi Desa
* **Sejarah & Visi Misi**: Latar belakang Desa Kromengan serta komitmen pelayanan.
* **Wilayah Dusun**: Informasi 3 Dusun utama (*Dusun Krajan, Dusun Ringinanom, Dusun Balokan*).
* **Aparatur Desa**: Profil Kepala Desa, Sekretaris, Kasi, Kaur, Kepala Dusun, dan BPD.

### 📋 2. Layanan Publik Digital & Pengaduan
* **Pengajuan Surat Online**: Layanan mandiri surat keterangan desa beserta pelacak (*Tracking Tiket*).
* **Pengaduan Warga**: Formulir aspirasi dan keluhan langsung terhubung ke sistem desa.

### 🚜 3. Potensi Desa & UMKM
* **Komoditas Tebu & Agriculture**: Informasi sentra penghasil tebu rakyat dan sektor peternakan.
* **Katalog UMKM**: Promosi usaha lokal keripik, konveksi, dan produk ekonomi kreatif desa.

### 📊 4. Transparansi & Berita
* **Transparansi APBDes**: Visualisasi rinci anggaran pendapatan & belanja desa.
* **Kanal Berita & Pengumuman**: Informasi kegiatan masyarakat, posyandu, dan agenda desa.

## 🛠️ Teknologi yang Digunakan

* **Frontend Framework**: React 18 + TypeScript + Vite
* **Styling & UI**: Tailwind CSS + Lucide Icons
* **Animation Engine**: Motion (Framer Motion)
* **Backend Runtime**: Node.js + Express (Cloud Run / Full-Stack Ready)

## 💻 Cara Menjalankan Aplikasi Secara Lokal

### Persyaratan Sistem
* Node.js versi 18 atau lebih baru
* npm / yarn / bun

### Langkah-Langkah

```bash
# 1. Clone repository
git clone https://github.com/username/desa-kromengan.git

# 2. Masuk ke direktori
cd desa-kromengan

# 3. Install dependensi
npm install

# 4. Jalankan server pengembangan
npm run dev
```

Server lokal akan siap di `http://localhost:3000`.
